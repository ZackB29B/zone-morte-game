ZONE MORTE — LOBBY IMMERSIF

Améliorations de cette version :
- Lobby modernisé avec navigation dédiée : jouer, en ligne, arsenal, social, profil, réglages et identité.
- Profil combattant avec niveau calculé à partir de l'XP, barre de progression et statistiques.
- Personnalisation locale : nom d'appel, emblème et couleur d'interface.
- Paramètres avancés : qualité graphique et interface compacte.
- Présentation responsive pour téléphone et ordinateur.

Les fichiers server.js, online.js, package.json et grenades.js sont conservés depuis la version fournie.
Les statistiques utilisent les données déjà enregistrées par le jeu. La personnalisation visuelle est locale à l'appareil.
Voir INSTALLATION.txt pour le déploiement.
